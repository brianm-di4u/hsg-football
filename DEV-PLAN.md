## 2. File layout

```
games/football/
  index.html               generated by shared/tools/inline.mjs (do not edit)
  src/index.html           page shell, @inline data
  src/package.json         {"type":"module"} so tools can import src/js in Node
  src/styles/main.css
  src/js/{rng,data,roster,plays,steer,sim,rules,ai,league,art,field,audio,ui,main}.js
  data/schools.json        copy of shared/data/schools.json (build-data.mjs)
  data/facts.json          halftime facts (build-data.mjs, from the audited trivia bank)
  tools/build-data.mjs     regenerates data/
  tools/balance.mjs        Node outcome-distribution and AI-vs-AI checker
  tests/*.test.mjs, tests/helpers.mjs
```

Build: `node games/football/tools/build-data.mjs && node shared/tools/inline.mjs games/football`.

## 3. `window.__game` hook spec

| Hook | Returns / does |
|---|---|
| `seed(n)` | reseeds `S.rng`; returns `n` |
| `getState()` | `{ scene, settings, saveOk, game: { mode, teams:[{id,abbr,name}], home, quarter, clock, score, poss, ballOn, down, toGo, timeouts, phase, offCall, defCall, userOffense, live: {t, carrier, ballState, ballX, ballY, receivers:[{slot,x,y,open}]}, lastResult, log (last 5), ot, challenge, statsSummary, venue, rivalry, halftimeFact }, season: { year, userTeam, week, weeks, phase, schedule (user rows), standings, playoffs, champion }, challenges }` |
| `setState(p)` | deep-merges `p` into `S` (`settings`, `game.*`, `season.*`); clears a live play if `game.phase` is set; re-renders |
| `isIdle()` | `false` while a play is live, a kick or kickoff is animating, the camera is easing, a toast or screen is entering, or confetti is falling (and reduced motion is off) |
| `step(n)` | advances n fixed ticks (works while paused) |
| `pause()` / `resume()` | freezes or unfreezes the accumulator |
| `scene(name)` | `title, exhibition, seasonSetup, season, challenges, help, settings, game, halftime, final, champion` |
| `newGame(opts)` | `{ mode:'exhibition', home:'lakeside', away:'lake-hamilton', user:0\|1, quarterMin, seed, skipToss }` or `{ mode:'season', team, short }` or `{ mode:'challenge', id }` |
| `act('call', id)` | user offense: choose a play (`dive, sweep, draw, keeper, slants, verts, curls, postcorner, screen, playaction, punt, fg, kneel`) |
| `act('defCall', id)` | user defense: `base, man, shell, runstuff, blitz, spy` |
| `act('snap')` | snaps during `pre` |
| `act('throw', slot)` | throws to receiver slot 1–5 |
| `act('steer', dx, dy)` | sets the steering vector (screen space; `0,0` releases) |
| `act('juke')` | jukes |
| `act('finishPlay')` | runs the live play to its end instantly (same sim, same rng) |
| `act('kick', e)` | stops the needle at error `e` (−1..1); no argument = current needle |
| `act('pat', 'kick'\|'two')` | chooses the try |
| `act('timeout')` | user timeout |
| `act('advance')` | dismisses the result, break or splash; continues |
| `act('coin', 'heads'\|'tails')` | coin toss call |
| `act('simGame')` | quick-sims the rest of the current game |
| `act('autoplay', maxPlays)` | AI plays both sides to the end of the game, synchronously |
| `act('simWeek')` / `act('simSeason')` | season: sim the user's week / the rest of the season |
| `act('layout')` | viewport rects for buttons, cards, receivers and the carrier, for real-input tests |
| `act('animAt', ms)` | freezes the fx clock at `ms` into the current effect (toast, confetti, kick) and makes `isIdle()` true |
| `act('save')` / `act('hasSave')` | forces a save / reports whether a save exists |
| `act('kickoffGo')` | from the pregame splash (after the toss): kicks off |
| `act('forceResult', r)` | rules tests: applies a crafted play result (`{kind, yards, elapsed, clockStops, scorer, …}`) through the real `applyResult` |
| `act('td', ms)` | draws the touchdown burst frozen `ms` into its animation |
| `act('mascotSheet')` | renders all ten mascots on one screen for review |
| `act('audio')` | creates the audio context (as a gesture would) and reports `{ready, on, volume}` |
| `act('nextSeason')` / `act('seasonContinue')` | season flow from the final screen and the hub |

`getState()` also reports `loop` (whether the render loop is running), `reduced`, `saveOk`, `hasSave`, `fx` (live effect count) and, for the field, `live.receivers` (screen positions) and `live.engaged` (blocks in progress).
